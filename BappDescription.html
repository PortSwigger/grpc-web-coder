Decodes and re-encodes gRPC-Web request and response bodies in Burp's message editor, without needing the target's .proto schema.

gRPC-Web bodies are protobuf wrapped in length-prefixed frames, and application/grpc-web-text bodies are base64 on top of that. In Burp they arrive as an opaque blob, so ordinary testing techniques do not reach them. This extension unwraps the framing, infers a type for every protobuf field, and shows the result as editable JSON. Edits are re-encoded on the way out, so a payload can be tampered with in Proxy, Repeater and Intruder like any other request body.

Supported content types

  • application/grpc-web-text and application/grpc-web-text+proto
  • application/grpc-web+proto and application/grpc-web

What it does

  • Adds a Decoded gRPC-Web tab to requests and responses, with the payload as JSON and an editable type definition alongside it.
  • Guesses a type for each field from the wire format, and lists the other readings the same bytes would allow, so an ambiguous field can be reinterpreted without trial and error.
  • Handles every frame in a body, including the multiple data frames of a server-streaming response and the trailer frame that closes it.
  • Inflates and re-deflates gzip-compressed frames.
  • Supports proto3 packed repeated fields, which are indistinguishable from a bytes field on the wire.
  • Extracts service routes and message field definitions from generated gRPC-Web JavaScript, via Analyze gRPC-Web Endpoints on the right-click menu, revealing methods that no part of the application's UI calls.
  • Exports those findings as JSON, CSV, a reconstructed .proto for protoc or grpcurl, or as type definitions to paste back into the Type Definition tab so payloads decode with their real field names.

Getting started

Send a gRPC-Web request through Burp and open the Decoded gRPC-Web tab in Repeater. Field names are not carried on the wire, so fields appear by number until you name them in the type definition. Running the JavaScript analyzer over the site's gRPC-Web bundle recovers the real names and numbers; exporting its results as type definitions and pasting them into the Type Definition tab makes every subsequent payload readable.

For a walkthrough of testing gRPC-Web, see grpc-pentest-suite.
